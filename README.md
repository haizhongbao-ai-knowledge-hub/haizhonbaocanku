# 海中宝AI总文件

这是海中宝AI项目的统一项目记忆中心，用来连接：

- 老板的公司方向与日常思考
- ChatGPT 的规划、分析、复盘能力
- Codex 的执行、改文件、跑命令、调试能力
- 2-3 台电脑上的长期工作状态

这个项目预计持续投入 3-6 个月，并会随着工作推进不断优化、细化和沉淀。

## 每次开始工作先读

1. `PROJECT_BRIEF.md`
2. `KNOWLEDGE_HUB.md`
3. `knowledge-hub/CONFIRMED_KNOWLEDGE.md`
4. `knowledge-hub/UNCONFIRMED_IDEAS.md`
5. `OPERATING_MODEL.md`
6. `COLLAB_PROTOCOL.md`
7. `TASKS.md`
8. `AGENTS.md`
9. `HANDOFF.md`

## 日常工作流

1. 在 ChatGPT 的“海中宝AI”窗口里讨论方向、业务、产品、管理和策略。
2. 把重要输出导入 `GPT_OUTLINE_IMPORT.md`。
3. 将确认后的内容沉淀到 `PROJECT_BRIEF.md`、`TASKS.md`、`DECISIONS.md`。
4. 让 Codex 按项目文件执行具体任务，并更新 `HANDOFF.md`。
5. 通过 Git/GitHub 在多台电脑之间同步。
6. 需要让 GPT 理解协作方式时，复制 `PROMPT_FOR_GPT.md` 给它。
7. 需要家里电脑接入时，读取 `家里电脑接入说明.md`。

## 使用原则

- 与海中宝AI强相关的内容，优先沉淀到这个项目文件夹。
- 与项目关系不大的一般咨询，放到其他聊天窗口，避免污染项目记忆。
- 项目文件是事实来源，聊天历史只是过程材料。
- GPT 负责方案与方向，Codex 负责复核与执行。
- 老板确认后再进入执行。
- GPT 确认后的交接内容可以先进入 `inbox/gpt-handoffs`，再由脚本归档到 `REQUIREMENTS_TABLE.md`。
- 已确认知识进入 `knowledge-hub/CONFIRMED_KNOWLEDGE.md`。
- 未确认想法进入 `knowledge-hub/UNCONFIRMED_IDEAS.md`。
- 聊天记录摘要进入 `knowledge-hub/CHAT_RECORDS_INDEX.md`。
- GitHub 仓库是多电脑同步中心：`https://github.com/haizhongbao-ai-knowledge-hub/haizhonbaocanku`。
