# 海中宝AI优盘/手机随身接入包

状态：【老板使用版】

更新日期：2026-07-29

## 一、结论

平时给新GPT、新Codex、新AI专家，优先只给一个文件：

```text
海中宝AI中央大脑智能体一键接入入口_V2.0.md
```

这个文件的作用是让AI进入中央大脑接入流程。

它不是全部资料，也不等于全部权限。

## 二、老板账号随身包

老板自己的优盘或手机文件夹建议保存：

```text
01_唯一入口文件
02_老板备用核心资料
03_给Codex桌面版
04_二次授权再给
05_禁止存放敏感信息
```

## 三、给不同对象的规则

### 1. 新GPT浏览器版

第一次只给：

```text
海中宝AI中央大脑智能体一键接入入口_V2.0.md
```

让它输出：

```text
《海中宝AI中央大脑接入申请》
```

确认岗位和权限后，再按需要上传第二批文件。

### 2. 新Codex桌面版

第一次给：

```text
海中宝AI中央大脑智能体一键接入入口_V2.0.md
```

如果它能访问GitHub，则让它克隆中央仓库。

如果它不能访问GitHub，再给 `03_给Codex桌面版` 里的备用文件。

### 3. AI专家

第一次只给入口文件。

AI专家默认P0观察员。

必须经过：

```text
身份识别
↓
岗位选择
↓
权限申请
↓
老板授权
↓
加载对应知识库
```

## 四、核心原则

不是授权账号。

而是授权智能体身份。

同一个GPT账号可以今天作为HR AI，明天作为产品AI。

真正决定权限的是：

- 当前AI身份
- 服务岗位
- 权限等级
- 老板授权
- 中央大脑权限文件

## 五、禁止

优盘和手机里不要保存：

- GitHub密码
- ChatGPT密码
- 企业微信密码
- API Key
- 真实业务系统密码
- 员工隐私
- 候选人隐私
- 财务原始敏感数据
