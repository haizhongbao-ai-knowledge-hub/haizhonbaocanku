# 企业经营事实层

这里存放海中宝的授权经营事实层知识。

用途：

- 给战略AI统一企业认知基础。
- 给经营数据AI提供日报和看板底座。
- 给财务战略AI提供降本增效与风险判断基础。
- 给HR AI提供组织与人才设计背景。
- 给产品AI提供商业模式与经营约束。
- 给未来风控/质疑类AI提供经营风险线索。

## 目录

| 文件 | 用途 |
| --- | --- |
| `海中宝AI中央大脑企业经营事实层知识库_V1.0.md` | 公司主体、商业模式、组织管理、经营事实、AI使用说明 |
| `海中宝经营指标字典_V1.0.md` | 经营日报和驾驶舱指标口径、公式、来源、待确认项 |

## 读取原则

1. 只作为授权经营资料层。
2. 不能替代原始业务系统。
3. 不能替代老板确认。
4. 不能把敏感经营数据放入公开接入包。
5. 任何指标口径变更必须进入同步记录。
