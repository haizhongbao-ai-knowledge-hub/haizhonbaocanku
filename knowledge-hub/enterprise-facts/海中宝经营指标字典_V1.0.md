# 海中宝经营指标字典 V1.0

状态：【草案，待老板确认】

更新日期：2026-07-31

## 一、用途

本文件用于统一海中宝经营日报和老板驾驶舱的指标口径。

## 二、核心指标字典

| 指标 | 含义 | 基本公式 / 口径 | 数据来源建议 | 状态 |
| --- | --- | --- | --- | --- |
| GMV | 商品交易总额 | 所有成交订单金额总和 | 电商平台 / ERP | 待确认 |
| 订单数 | 成交订单数量 | 所有完成或成交订单计数 | 电商平台 / ERP | 待确认 |
| 客单价 | 每单平均成交额 | GMV / 订单数 | 电商平台 / ERP | 待确认 |
| 平台贡献 | 平台对总业绩的贡献占比 | 平台GMV / 总GMV | 电商平台汇总 | 待确认 |
| 采购成本 | 采购支出总额 | 采购明细汇总 | 采购单 / 供应商对账 | 待确认 |
| 投流成本 | 广告投放支出 | 广告费用汇总 | 广告平台开户 / 财务 | 待确认 |
| 人工成本 | 员工工资及相关支出 | 工资、社保、福利等汇总 | 薪酬表 / 财务 | 待确认 |
| 物流成本 | 发货、运输、仓配费用 | 物流支出汇总 | 物流单 / 财务 | 待确认 |
| 毛利 | 收入减去直接成本 | 收入 - 采购成本 - 直接履约成本 | 财务 / ERP | 待确认 |
| 净利润 | 最终盈利 | 收入 - 所有成本费用 - 税费 | 财务汇总 | 待确认 |
| 单品利润 | 单个SKU或单品毛利/净利 | 售价 - 单品成本 - 分摊成本 | 商品表 / 财务 | 待确认 |
| 渠道利润 | 某渠道的盈利能力 | 渠道收入 - 渠道成本 - 渠道分摊费用 | 渠道看板 / 财务 | 待确认 |
| 复购率 | 老客户再次购买比例 | 复购客户数 / 总客户数 或 复购订单数 / 总订单数 | 客户与订单系统 | 待确认 |
| 库存周转 | 库存流转速度 | 销售成本 / 平均库存 | 仓储 / ERP | 待确认 |
| 库存准确率 | 实物与系统匹配程度 | 一致SKU数 / 总SKU数 | 仓库盘点 / ERP | 待确认 |

## 三、重点说明

1. `GMV` 不是净利润。
2. `毛利` 不等于 `净利润`。
3. `渠道利润` 必须单独核算，不能只看总销售额。
4. `复购率` 口径需要老板确认后统一。
5. `库存准确率` 和 `库存周转` 需要和仓库规则一起定义。

## 四、经营日报优先指标

建议老板经营日报第一版先看：

1. 总GMV
2. 总订单数
3. 总毛利
4. 渠道利润
5. 异常预警
6. 复购情况
7. 投流成本
8. 采购成本
9. 人工成本
10. 物流成本

## 五、口径待确认项

以下内容暂不作为最终口径：

- GMV是否按退款前或退款后计算
- 毛利是否含运费
- 净利润是否含税费
- 渠道利润分摊规则
- 单品利润分摊规则
- 复购率公式
- 平台贡献公式

## 六、与事实层关系
