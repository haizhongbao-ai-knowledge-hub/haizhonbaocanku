状态：【执行评估完成，待老板确认】

项目编号：HZB-BOSS-COCKPIT-V2-001

## 一、项目定位

老板驾驶舱 V2.0 是海中宝AI中央大脑给老板看的统一入口。

它不是单独的数据看板，也不是替代经营日报。

它负责把以下内容汇总到一个老板可快速判断的界面/文件：

- AI项目状态
- 老板经营日报
- AI专家意见
- 待老板决策
- 风险提醒
- 下一步优先级
