## 一、项目定位

老板经营日报 MVP 是海中宝AI中央大脑进入真实经营应用的第一批重点项目。

第一版目标不是一次性打通所有系统，而是用最小可用方式让老板每天看清：

- 今天卖了多少。
- 哪些渠道贡献最大。
- 哪些成本异常。
- 哪些产品、店铺或类目值得关注。
- 哪些事项需要老板决策。
