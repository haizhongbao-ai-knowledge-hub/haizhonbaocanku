# 老板经营日报 MVP 数据字段清单 V1.0

状态：【字段草案，待样例数据验证】

项目编号：HZB-BOSS-DAILY-MVP-001

更新日期：2026-08-03

## 一、用途

本文件定义老板经营日报MVP第一版建议采集的Excel/CSV字段。

第一版目标：

- 先统一字段。
- 再导入样例数据。
- 再生成日报。
- 最后决定是否自动化。

| 字段 | 含义 | 是否必填 | 示例 | 备注 |

## 五、日报输出指标

| 指标 | 公式 / 口径 | 第一版状态 |
| --- | --- | --- |
| GMV | 销售金额汇总 | 待确认退款口径 |
| 净销售额 | 销售金额 - 退款金额 | 建议采用 |
| 订单数 | 订单号去重数量 | 待确认平台口径 |
| 客单价 | GMV / 订单数 | 可计算 |
| 毛利 | 净销售额 - 采购总成本 - 发货成本 - 平台成本 | 第一版估算 |
| 毛利率 | 毛利 / 净销售额 | 第一版估算 |
| 投流ROI | 投流成交金额 / 投流成本 | 需要广告数据 |
| 渠道利润 | 渠道净销售额 - 渠道成本 | 第一版估算 |
| 库存可售天数 | 当前库存 / 近7日平均销量 | 可计算 |

## 六、异常规则

| 异常 | 判断方式 | 提醒级别 |
| --- | --- | --- |
| GMV下降 | 较前一日或近7日均值下降超过20% | 中 |
| 毛利率过低 | 低于老板确认阈值 | 高 |
| 投流ROI异常 | ROI低于老板确认阈值 | 高 |
| 库存断货风险 | 可售天数低于3天 | 高 |
| 库存积压风险 | 可售天数高于60天 | 中 |
| 退款异常 | 退款金额占比超过阈值 | 中 |

## 七、第一版数据文件建议

建议老板或负责人先准备3张脱敏表：

1. 销售明细表。
2. 成本明细表。
3. 库存明细表。

文件格式：

```text
.xlsx / .csv
```

第一版只需要近7天数据即可。

## 八、未确认事项

- GMV按退款前还是退款后。
- 平台成本是否计入毛利。
- 发货成本是否按订单分摊。
- 人工成本是否进入第一版日报。
- B端和线下数据是否与电商平台同表汇总。
- 老板最关心的5个指标。

## 九、安全要求

上传给AI或进入GitHub前必须脱敏：

- 删除客户手机号、地址、身份证等个人信息。
- 删除员工工资个人明细。
- 删除平台登录账号和密码。
- 删除银行卡、私账流水明细。
- 删除供应商敏感结算账号。

中央大脑第一版只保存字段模板、口径和脱敏样例。
