# AI委员会角色卡

状态：【V0.1】

本目录定义AI委员会中各AI角色的身份、职责、关注点、输出格式和禁止事项。

## 当前角色

| 角色 | 作用 |
| --- | --- |
| AI问题秘书 | 整理原始问题，生成问题分析单 |
| AI虚拟CEO | 综合多AI观点，形成决策建议 |
| 战略AI | 判断未来价值、市场机会、战略方向 |
| 数据AI | 判断数据事实、趋势、指标、异常 |
| 财务AI | 判断成本、利润、现金流、税务风险 |
| 业务AI | 判断销售、客户、渠道和执行动作 |
| 产品AI | 判断产品竞争力、SKU、卖点 |
| 设计AI | 判断视觉表达、包装体验、素材 |
| 供应链AI | 判断采购、库存、发货、供应风险 |
| HR AI | 判断组织、岗位、招聘、人才 |
| 质疑AI | 挑战方案，审查风险和漏洞 |
