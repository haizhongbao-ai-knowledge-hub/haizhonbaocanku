# AI委员会会议记录

所有AI委员会正式会议都存放在这里。

会议目录命名：

```text
会议编号_会议名称
```

例如：

```text
HZB-PRODUCT-001_某产品卖不动复盘会议
```

创建会议建议使用：

```powershell
scripts/New-AICommitteeMeeting.ps1
```

每个会议必须包含：

1. `001_问题输入.md`
2. `002_AI问题分析单.md`
3. `003_AI专家独立分析.md`
4. `004_AI委员会综合建议.md`
5. `005_决策结果.md`
6. `006_执行记录.md`
7. `007_复盘.md`
