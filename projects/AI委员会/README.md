# 海中宝AI委员会

项目编号：HZB-AI-COMMITTEE-001

状态：【V0.1 建设中】

负责人：

- 春晓V0（Owner）
- 伟强V1（AI项目推进负责人）

## 一、项目定位

海中宝AI委员会不是聊天群。

它是中央大脑中的企业AI决策会议系统。

目标：

```text
业务问题
↓
AI问题秘书整理
↓
多岗位AI专家独立分析
↓
AI虚拟CEO综合
↓
春晓V0决策
↓
伟强V1推进
↓
Codex执行
↓
知识沉淀
```

## 二、核心原则

1. 不创建第二套中央大脑。
2. 所有会议文件进入现有 `projects/AI委员会/`。
3. 会议结论和决策进入 `knowledge-hub`、`DECISIONS.md`、`sync_records`。
4. AI身份独立于设备、GPT账号和电脑。
5. 所有AI讨论必须形成结果，禁止无限聊天。

## 三、目录

| 目录 | 用途 |
| --- | --- |
| `templates/` | 会议创建、问题输入、AI分析、综合建议、决策、执行、复盘模板 |
| `roles/` | AI委员会角色卡 |
| `meetings/` | 所有正式会议记录 |
| `meeting-types/` | 产品、财务、招聘、战略等会议分类 |

## 四、V0.1实现方式

第一阶段采用：

```text
GPT + Codex + GitHub中央文件
```

暂不开发APP。

先验证：

- 问题整理
- 专家协同
- 综合建议
- 老板决策
- 结果归档

## 五、验收标准

V0.1完成后，必须支持：

- 员工提出问题。
- AI问题秘书整理问题。
- 多个AI专家输出独立观点。
- AI虚拟CEO输出综合建议。
- 春晓V0收到需确认事项。
- 伟强V1可推进执行。
- Codex可按正式文件执行。
- 决策和复盘进入中央大脑。
