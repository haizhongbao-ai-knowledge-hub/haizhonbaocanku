# AI委员会会议分类

状态：【V0.1】

## 分类

| 会议类型 | 目录 | 适用问题 |
| --- | --- | --- |
| 产品开发会议 | `产品开发会议/` | 新品、老品优化、包装、卖点、用户反馈 |
| 财务优化会议 | `财务优化会议/` | 成本、利润、现金流、税务、资金 |
| 招聘会议 | `招聘会议/` | 岗位、人才画像、招聘渠道、面试、组织 |
| 战略会议 | `战略会议/` | 公司方向、业务取舍、重大投资、组织策略 |

每类会议仍统一归入：

```text
projects/AI委员会/meetings/
```

`meeting-types/` 只做分类说明。
