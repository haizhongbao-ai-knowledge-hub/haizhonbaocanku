# BOSS沟通话术

状态：【MVP模板】

## 初次打招呼

```text
您好，我是海中宝招聘负责人。看到您的经历和我们正在招聘的【岗位名称】比较匹配，想和您简单沟通一下机会。
```

## 了解意向

```text
方便了解一下您目前是否在看新的工作机会？您比较关注岗位的哪些方面？
```

## 介绍岗位

```text
这个岗位主要负责【核心职责】，我们更看重【关键能力】。如果您方便，我可以进一步发岗位信息给您。
```

## 约面试

```text
如果您对岗位有兴趣，我们可以约一个时间简单沟通。您这两天哪个时间段方便？
```

## 风险提示

话术只能作为建议，不能自动发送。

涉及薪酬、录用承诺、公司敏感信息时，必须由负责人确认。
