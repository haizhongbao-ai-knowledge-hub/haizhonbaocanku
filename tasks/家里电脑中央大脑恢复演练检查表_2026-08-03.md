4. Codex 能识别身份、权限和任务。
5. GPT 能通过项目资料恢复上下文。

## 三、家里电脑恢复流程

### Step 1：登录账号

登录：

1. GitHub账号
2. ChatGPT账号
3. Codex账号

可以是同一个账号，也可以是新账号。

原则：账号不同没关系，必须通过入口文件和权限文件确认身份。

### Step 2：安装基础工具

检查：

| 项目 | 要求 |

| Chrome | 可以打开 GitHub 和 ChatGPT |
| ChatGPT | 浏览器版即可 |
| Codex | 桌面版或可用执行环境 |
| Git | 能执行 clone、pull、push |

## 四、Codex接入测试

在家里电脑打开 Codex 后，第一句话复制：

```text
你现在接入海中宝AI中央大脑。请先读取本地仓库入口文件、中央大脑导航地图、项目状态总览、AI身份权限验证表，然后输出《当前理解确认》。当前设备为家里电脑，请判断是否完成中央大脑恢复演练，不要直接修改核心规则。
```


1. 不把聊天记录当事实来源。

3. 能区分老板、GPT、Codex、AI专家角色。
4. 能说明未授权前不能执行核心修改。
