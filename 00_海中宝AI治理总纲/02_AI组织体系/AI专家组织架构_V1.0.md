# AI专家组织架构 V1.0

状态：【确认方向，细节待完善】

## 一、第一阶段建议建设AI专家排序

### 第一优先级

#### 1. 老板战略AI

优先级：⭐⭐⭐⭐⭐

原因：所有项目入口。

负责：

- 公司方向
- 战略判断
- 重大决策

#### 2. 经营数据AI

优先级：⭐⭐⭐⭐⭐

原因：老板驾驶舱基础。

负责：

- 销售
- 成本
- 毛利
- 利润
- 异常

#### 3. 财务战略AI

优先级：⭐⭐⭐⭐⭐

定位：财务总监 + 税务筹划顾问。

负责：

- 财务分析
- 税务优化
- 投资回报
- 成本控制

#### 4. 营销增长AI

优先级：⭐⭐⭐⭐

负责：

- 品牌
- 用户
- 渠道
- 内容
- 增长

#### 5. 产品战略AI

优先级：⭐⭐⭐⭐

负责：

- 产品规划
- 产品标签
- 包装设计
- 产品价值表达

## 二、第二阶段待完善AI

- 供应链AI
- 客服AI
- 招聘AI
- 人力AI
- 法务AI
- 采购AI

## 三、Codex复核意见

建议第一阶段不要同时落地过多 AI 专家。

建议先按“三个核心专家”启动：

1. 老板战略AI
2. 经营数据AI
3. 财务战略AI

营销增长AI和产品战略AI可作为第二批，但先保留设计。
