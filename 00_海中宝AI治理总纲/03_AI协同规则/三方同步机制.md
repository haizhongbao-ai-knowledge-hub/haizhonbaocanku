# 三方同步机制

状态：【已确认，持续执行】

## 核心原则

重要事项必须保证：

```text
老板知道
GPT理解
Codex同步
```

否则不能进入执行。

## 执行状态

| 状态 | 含义 | 是否允许执行 |
| --- | --- | --- |
| 待同步 | Codex未收到正式同步文件 | 否 |
| 待确认 | 三方已同步，但仍有关键问题未确认 | 否 |
| 允许执行 | 老板、GPT、Codex均已确认 | 是 |
| 已完成 | 已执行并复盘 | 否，除非开启下一轮 |

## 记录位置

三方同步确认记录统一放入：

```text
sync_records/
```
