# 统一任务入口与推荐派单规则

版本：V1.0

状态：【P0-02/P0-03共用规则】

## 一、唯一正式任务入口

V0确认后的正式任务文件，只投递一次。

运行目录：

```text
D:\海中宝AI协同中心\00_统一任务入口\00_待识别
```

目录结构：

```text
00_统一任务入口/
├── 00_待识别/
├── 01_待补充/
├── 02_已派单/
├── 03_执行中/
├── 04_待审批/
├── 05_已完成/
└── Archive/
```

## 二、处理流程

```text
V0 GPT确认正式任务
↓
保存到统一任务入口/00_待识别
↓
Dispatcher识别与推荐
↓
V0确认或低风险自动派单
↓
V0 Codex / V2 Codex / 伟强V1 / AI委员会
↓
执行与回传
↓
V0审批
↓
V2正式归档GitHub
↓
状态中心、Heartbeat、老板驾驶舱更新
```

## 三、推荐派单初期规则

当前阶段采用：

```text
推荐派单 + V0确认
```

连续10个真实任务稳定后，才允许低风险任务自动派单。

## 四、自动派单启用条件

必须同时满足：

1. V2接口稳定。
2. 连续10个真实任务无重大错误。
3. 任务锁和分支规则稳定。
4. 自动派单准确率达到设定标准。
5. V0正式批准。

启用后：

1. R0/R1低风险任务可自动派单。
2. R2/R3仍需V0确认。

## 六、节点分配

| 节点 | 适用任务 |
| --- | --- |
| V0 Codex | 30分钟以内、不超过3个文件、查询、检查、小修订 |
| V2 Codex | 超过30分钟、5个以上文件、中央治理、自动化、接口、脚本、正式归档 |
| 伟强V1 | 财务口径、经营数据、公司真实业务资料、部门资料补充 |
| AI委员会 | 战略、多方案比较、重大经营风险、多专家分析 |

## 七、禁止事项

1. 禁止多个Codex自由并发修改中央仓库。
2. 禁止V0继续手工判断每个任务发给谁。
3. 禁止V2上线后仍等待人工逐项告诉它做什么。
4. 禁止V3-V6重新设计另一套接入流程。
