# 中央接入协议 V3.0

状态：【V0-V1-V2岗位接入升级版】

更新日期：2026-08-03

## 一、定位

V3.0不是替代V2.0入口文件。

V2.0入口文件继续作为长期稳定启动器。

V3.0负责定义：

1. 接入后先读取什么。
2. 如何验证身份。
3. 如何加载岗位知识包。
4. 如何生成资料缺失清单。
5. 如何进入正式工作模式。

## 二、固定流程

```text
读取Project State
↓
读取公共治理规则
↓
身份与权限验证
↓
加载岗位知识包
↓
加载当前项目包
↓
生成岗位资料缺失清单
↓
进入正式工作模式
```

## 五、禁止事项

1. 禁止所有账号一接入就读取全部公司资料。
2. 禁止绕过身份权限验证。
3. 禁止新AI直接修改宪法、状态中心、权限文件。
4. 禁止未授权读取财务、员工、客户敏感资料。
