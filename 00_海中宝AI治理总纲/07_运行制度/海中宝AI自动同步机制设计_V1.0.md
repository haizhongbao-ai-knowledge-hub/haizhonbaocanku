# 海中宝AI自动同步机制设计 V1.0

状态：【设计版，允许先用半自动脚本验证】

更新日期：2026-07-27

## 一、目标

建立AI中央大脑的同步提醒机制，减少老板在GPT、Codex、不同电脑、不同账号之间反复复制资料。

核心目标：

- 检测GitHub和本地仓库文件变化。
- 生成AI同步通知。
- 标明变化影响哪些AI。
- 判断是否需要老板确认。
- 判断是否需要Codex执行。

## 二、当前阶段判断

当前不直接做复杂自动化机器人。

第一阶段采用：

```text
GitHub + 本地仓库 + 同步通知脚本 + 人工确认
```

原因：

- 项目规则仍在快速升级。
- 自动同步不能绕过老板确认。
- GPT目前不能稳定自动读取本地文件。
- 微信、企业微信、QQ等工作群接入仍需技术评估。

## 三、同步检测范围

重点检测：

| 文件类型 | 影响 |
| --- | --- |
| `海中宝AI项目状态总览.md` | 影响所有AI对当前进度的理解 |
| `KNOWLEDGE_HUB.md` | 影响知识地图 |
| `00_海中宝AI治理总纲/` | 影响宪法、权限、协同和运行规则 |
| `TASKS.md` | 影响当前任务 |
| `HANDOFF.md` | 影响跨电脑交接 |
| `接入包_给GPT和Codex/` | 影响新账号和新电脑接入 |
| `projects/` | 影响具体项目执行 |

## 四、AI同步通知格式

同步通知文件保存到：

```text
sync_records/
```

文件命名：

```text
AI同步通知_YYYYMMDD-HHMMSS.md
```

内容格式：

```text
# AI同步通知

生成时间：

触发来源：

## 一、变化文件

| 文件 | 变化类型 | 说明 |

## 二、影响AI

| AI | 影响 | 是否需要读取 |

## 三、是否需要老板确认

是 / 否 / 待判断

## 四、是否需要Codex执行

是 / 否 / 待判断

## 五、建议下一步
```

## 五、影响AI判断规则

| 变化位置 | 影响AI |
| --- | --- |
| `00_海中宝AI治理总纲/01_AI宪法/` | 所有AI |
| `00_海中宝AI治理总纲/02_AI组织体系/` | 所有AI专家、GPT、Codex |
| `00_海中宝AI治理总纲/03_AI协同规则/` | GPT、Codex、所有AI专家 |
| `00_海中宝AI治理总纲/07_运行制度/` | GPT、Codex、所有新接入AI |
| `TASKS.md` | Codex、GPT |
| `HANDOFF.md` | Codex、新电脑、新账号 |
| `projects/` | 相关项目AI、Codex |

## 六、老板确认判断规则

需要老板确认：

- 宪法级规则变化。
- 权限变化。
- 项目优先级变化。
- 重要业务目标变化。
- 涉及成本、时间、人员或外部系统接入。

不一定需要老板确认：

- 错别字修正。
- 文件格式整理。
- 已确认内容的归档。
- 不改变规则含义的索引更新。

## 七、Codex执行判断规则

需要Codex执行：

- 要修改仓库文件。
- 要运行Git同步。
- 要写脚本、代码或自动化流程。
- 要创建项目目录、任务书、模板或报告。

不需要Codex执行：

- GPT单纯做战略分析。
- 老板单纯确认方向。
- 不进入仓库的普通聊天。

## 八、第一阶段脚本

第一阶段脚本：

```text
scripts/New-AiSyncNotice.ps1
```

用途：

- 尝试拉取GitHub最新状态。
- 对比本地和GitHub差异。
- 生成一份同步通知草稿。

说明：

- 网络失败时，脚本仍可记录本地未推送变化。
- 同步通知是提醒，不自动替代老板确认。
- 后续可以升级为定时任务、GitHub Actions或企业微信通知。
