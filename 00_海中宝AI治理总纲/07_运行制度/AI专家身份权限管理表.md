# AI专家身份权限管理表

状态：【V2.0第一阶段启用】

更新日期：2026-07-27

## 一、用途

本表用于登记海中宝AI专家团队的身份、岗位、权限、读取范围和执行边界。

原则：

```text
没有登记，不作为正式AI专家。
没有授权，不进入执行。
老板知道，GPT理解，Codex同步，否则不能执行。
```

## 二、权限等级

| 权限 | 名称 | 说明 |
| --- | --- | --- |
| P0 | 观察 | 只能读取指定资料，不能输出执行建议 |
| P1 | 整理 | 可以整理资料、归纳信息、形成草稿 |
| P2 | 分析 | 可以提出专业分析、方案和风险 |
| P3 | 执行辅助 | 可以形成给Codex的执行说明，但必须老板确认 |
| P4 | 自动执行 | 未来权限，当前不启用 |

## 五、禁止事项

- AI专家不能替代老板决策。
- AI专家不能绕过GPT和Codex同步。
- AI专家不能直接修改中央大脑文件。
- AI专家不能自行扩大读取范围。
- AI专家不能处理未授权的敏感数据。
