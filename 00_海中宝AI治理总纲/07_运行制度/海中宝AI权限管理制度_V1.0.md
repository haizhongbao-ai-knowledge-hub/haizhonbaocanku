# 海中宝AI权限管理制度 V1.0

状态：【V1.1升级启用】

更新日期：2026-07-28

## 一、目的

建立海中宝AI数字员工统一权限体系。

本制度继续采用P0-P4权限等级。

## 二、权限等级

| 权限等级 | 名称 | 可以做 | 不能做 |
| --- | --- | --- | --- |
| P0 | 基础读取 | 阅读公开知识，了解项目规则 | 修改文件，输出执行方案，读取敏感资料 |
| P1 | 信息整理 | 整理资料，总结信息，建立知识结构 | 直接执行任务，修改核心规则 |
| P2 | 专业分析 | 行业分析，专业建议，方案设计 | 自动决策，绕过老板确认 |
| P3 | 项目执行支持 | 输出Codex执行方案，创建任务说明，参与项目推进 | 未经老板确认直接执行 |
| P4 | 高级战略分析 | 企业经营分析，战略建议，多方案评估 | 自动决策，替代老板最终决策 |

## 三、权限使用规则

- P0只能作为观察和基础理解。
- P1可以整理资料，但不能代表最终结论。
- P2可以提出专业建议，但重要建议必须进入三方同步。
- P3可以推动项目执行准备，但Codex执行前必须有老板确认。
- P4是高级战略分析权，不是自动决策权。

最终决策者永远是老板。

## 四、典型岗位权限

| AI | 建议权限 | 说明 |
| --- | --- | --- |
| GPT战略助手 | P2-P3 | 分析、方案、交接Codex任务 |
| Codex执行助手 | P3 | 技术复核、文件维护、开发执行 |
| 战略AI | P4 | 战略分析、多方案评估，不做最终决策 |
| 经营数据AI | P3 | 经营日报、指标分析、异常提醒 |
| 财务战略AI | P2-P3 | 财务分析、利润结构、税务筹划建议 |
| 招聘AI | P2 | 招聘方案、JD、人才画像、面试体系 |

## 五、敏感权限规则

涉及以下内容时，必须老板确认：

- 财务核心数据
- 员工隐私
- 老板战略敏感文件
- 经营原始数据
- 外部账号权限
- 自动执行权限

## 六、禁止事项

- 任何AI不得自动获得全部权限。
- 任何AI不得自行扩大读取范围。
- 任何AI不得把建议当作老板最终决定。
- 任何AI不得把真实密码、口令、密钥写入仓库。
