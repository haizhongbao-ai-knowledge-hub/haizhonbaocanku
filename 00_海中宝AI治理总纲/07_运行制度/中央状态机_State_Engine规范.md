# 中央状态机（State Engine）规范

版本：V1.0

状态：【V2.1核心治理规范】

## 一、目的

让海中宝AI中央大脑围绕状态运行，而不是围绕聊天窗口运行。

任何GPT、Codex、AI专家开始工作前，第一步读取State。

## 二、State定义

State是当前中央大脑的可执行状态集合，包括：

1. 当前项目阶段。
2. 当前任务。
3. 下一步。
4. 负责人。
5. 等待事项。
6. 最新决策。
7. 更新时间。
8. 当前风险。

## 三、State入口

一级入口：

`00_老板驾驶舱/01_项目状态中心.md`

二级状态：

| 状态类型 | 文件 |
| --- | --- |
| 任务状态 | `TASKS.md` |
| 决策状态 | `DECISIONS.md` |
| AI状态 | `00_海中宝AI治理总纲/07_运行制度/AI状态中心.md` |
| 资产状态 | `00_海中宝AI治理总纲/07_运行制度/AI资产管理系统.md` |
| 会议状态 | `00_老板驾驶舱/04_AI委员会状态.md` |
| 经营日报状态 | `00_老板驾驶舱/05_经营日报状态.md` |

## 四、AI启动流程

```text
读取中央项目索引
↓
读取项目状态中心
↓
判断当前任务状态
↓
检查重复议题
↓
确认身份和窗口职责
↓
读取对应知识库
↓
输出当前理解确认
↓
等待老板或授权负责人确认
```

## 五、状态更新规则

任何重要事项完成后，必须更新：

1. `00_老板驾驶舱/01_项目状态中心.md`
2. `TASKS.md`
3. 必要时更新 `DECISIONS.md`
4. 必要时生成 `sync_records/三方同步确认记录/`

## 六、状态字段

标准状态：

| 状态 | 定义 |
| --- | --- |
| 已完成 | 文件、规则或任务已经完成并归档 |
| 已确认 | 老板认可方向，可推进 |
| 进行中 | 正在执行 |
| 待执行 | 已有任务但未开始 |
| 待确认 | 需要老板或授权负责人确认 |
| 待同步 | GPT、Codex、老板之间尚未同步 |
| 暂停 | 暂不推进 |
| 废弃建议 | 不建议继续使用，但不删除历史 |

## 七、禁止事项

1. 禁止AI不读取State直接执行。
2. 禁止用聊天记忆覆盖State。
3. 禁止只更新局部文件、不更新状态中心。
4. 禁止状态文件和执行文件互相矛盾。
