# 海中宝AI中央仓库资料加载规则 V1.0

状态：【启用】

更新日期：2026-07-29

## 一、目的

解决新GPT、新Codex、新电脑、新账号、新AI专家接入时，老板需要反复上传很多文件的问题。

最终目标：

老板只提供一个入口文件。

后续项目资料、岗位资料、权限资料、状态资料，优先由AI按照中央导航地图从GitHub中央仓库或本地中央仓库读取。

## 二、核心原则

入口文件只负责接入。

中央仓库负责供给资料。

权限文件负责判断能读什么。

岗位知识库负责进入工作模式。

老板不负责反复搬运文件。

## 三、标准接入方式

新AI第一次接入时：

```text
老板提供一个入口文件
↓
AI读取入口文件
↓
AI识别海中宝AI中央大脑
↓
AI请求读取中央导航地图
↓
AI读取项目状态总览
↓
AI提交身份和岗位申请
↓
根据权限读取对应中央仓库文件
↓
进入岗位工作模式
```

## 四、资料加载优先级

第一优先级：

```text
GitHub中央仓库
```

用于：

- GPT浏览器版
- 新电脑
- 新账号
- 其他远程AI

第二优先级：

```text
本地中央仓库
```

用于：

- Codex桌面版
- 办公室电脑
- 已克隆仓库的家里电脑

第三优先级：

```text
优盘/手机随身包
```

用途：

- 网络不可用
- GitHub无法访问
- 新设备首次恢复
- 应急灾备

## 五、老板日常操作原则

老板日常只需要给：

```text
海中宝AI中央大脑智能体一键接入入口_V2.0.md
```

老板不需要默认给：

- 中央导航地图
- 项目状态总览
- AI权限表
- 岗位知识库
- 项目文件
- HR资料包
- 财务资料包
- 产品资料包

这些内容应由AI在获得授权后，从中央仓库读取。

## 六、什么时候才需要老板继续给文件

只有以下情况才需要老板补充文件：

1. AI无法访问GitHub中央仓库。
2. AI无法访问本地中央仓库。
3. 当前文件尚未归档到中央仓库。
4. 资料属于老板临时提供的新材料。
5. 涉及敏感资料，需要老板单独授权后临时上传。

除此之外，不把“让老板继续上传很多文件”作为默认流程。

## 七、AI专家资料加载规则

AI专家第一次接入：

只读取入口文件。

完成身份申请后：

根据岗位加载对应资料。

示例：

HR招聘AI：

```text
允许读取：
- HR招聘AI知识库
- 招聘AI项目文件
- 岗位资料
- 面试评价标准

禁止读取：
- 财务原始数据
- 老板未授权战略文件
- 员工隐私
```

财务AI：

```text
允许读取：
- 财务制度
- 成本模型
- 经营数据

禁止读取：
- 招聘候选人隐私
- 无关部门内部资料
```

Codex：

```text
允许读取：
- 工程文件
- 项目任务书
- 已确认规则
- 技术执行资料

执行限制：
- 未经老板确认，不自动执行商业决策
- 未经授权，不修改宪法级文件
```

## 八、手机/优盘包定位

手机/优盘包不是日常资料分发中心。

它的定位是：

- 入口文件保存
- 老板备用核心资料
- 网络故障时恢复
- GitHub不可用时应急

正常情况下：

```text
一个入口文件
↓
中央仓库
↓
权限判断
↓
岗位资料加载
```

## 九、未来升级方向

```text

```

## 十、每日18点后复核重试规则

如果某次资料上传、归档、同步、推送或入库未完成，不管原因是什么，都必须进入待重试状态。

每天 18:00 以后，系统或负责 Codex 必须重新审核：

1. 当天是否有未完成的上传资料。
2. 当天是否有未成功入库的文件。
3. 当天是否有未成功推送到GitHub的变更。
4. 当天是否有待补齐的授权资料。

复核后按以下顺序重试：

```text
未完成项清单
↓
重新确认文件位置
↓
检查是否满足权限和归档条件
↓
重新上传或重新推送
↓
再次记录同步结果
```

重试原则：

- 不因为失败一次就放弃。
- 不把未完成项当作已完成项。
- 不绕过老板确认补传敏感资料。
- 如果仍失败，继续保留为待完成状态，次日 18:00 后再次复核。

## 十一、永久原则

老板知道。

GPT理解。

Codex同步。

文件记录。

否则不能进入执行。
