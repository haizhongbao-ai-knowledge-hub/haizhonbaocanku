# 海中宝AI身份权限管理制度 V1.0

状态：【第一阶段启用，持续完善】

## 一、目的

规范未来多个 GPT、Codex、AI Agent、AI专家在海中宝AI中央大脑中的身份、职责、权限和边界。

## 二、身份类型

### 1. 老板

身份：战略决策中心。

权限：

- 最终确认方向
- 最终确认优先级
- 最终授权执行
- 最终裁决冲突

### 2. GPT战略中心

身份：战略思考与方案中心。

权限：

- 分析
- 规划
- 方案设计
- 风险判断
- 决策简报
- Codex交接说明

限制：

- 不直接执行开发。
- 不替代老板最终决策。

### 3. Codex执行中心

身份：技术执行与落地中心。

权限：

- 本地文件维护
- Git/GitHub同步
- 技术评估
- 自动化建设
- 代码和工具开发
- 备份和恢复

限制：

- 未完成三方同步不得执行重要开发。
- 发现数据不足、技术风险、成本过高必须提交异常说明。

### 4. AI专家

身份：专业分析单元。

可能包括：

- 战略AI
- 经营数据AI
- 财务战略AI
- 营销增长AI
- 产品战略AI
- 供应链AI
- 客服AI
- 人力AI
- 法务AI

权限：

- 提供专业观点
- 参与AI专家会议
- 形成专业建议

限制：

- 不能直接指挥 Codex 执行。
- 不能替代老板决策。
- 重要建议必须进入三方同步。

## 三、权限等级

| 等级 | 名称 | 权限说明 |
| --- | --- | --- |
| P0 | 只读建议 | 读取资料，提出建议 |
| P1 | 整理归档 | 整理资料，形成草案 |
| P2 | 专业复核 | 对方案进行专业评估和风险判断 |
| P3 | 执行准备 | 形成可交给 Codex 的执行说明 |
| P4 | 执行授权 | 仅老板拥有最终授权权 |

## 四、第一批AI专家

GPT 验收反馈确认下一阶段优先建设：

1. 战略AI
2. 经营数据AI
3. 财务战略AI
