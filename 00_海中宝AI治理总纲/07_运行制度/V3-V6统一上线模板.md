## 一、统一流程

未来V3-V6以及其它执行节点，全部走同一流程：

```text
设备登记
→ 中央入口
→ 身份认证
→ 岗位授权包
→ Execution Mode
→ 节点上线确认
→ Dispatcher登记
→ Heartbeat上线
→ 任务测试
→ 正式Online
```

## 三、上线前检查

1. 是否已登记设备。
2. 是否已读取中央项目索引。
3. 是否已读取项目状态中心。
4. 是否已完成身份认证。
5. 是否已加载岗位授权包。
6. 是否已建立Heartbeat。
7. 是否已在Dispatcher登记。
8. 是否完成一个测试任务。

## 四、安全边界

1. Execution Mode不等于Owner决策权。
2. 不修改Owner/V1权限。
3. 不开放敏感数据。
4. 不自由并发修改main。
5. 正式结果由V2统一归档GitHub，除非老板另行授权。
