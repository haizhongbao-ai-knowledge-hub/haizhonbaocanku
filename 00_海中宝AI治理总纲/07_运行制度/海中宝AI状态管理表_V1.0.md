# 海中宝AI状态管理表 V1.0

状态：【V2.0建设中，基础表已建立】

更新日期：2026-07-27

## 一、用途

本表用于记录海中宝AI体系内所有AI身份、职责、权限、负责人、当前任务、版本和状态。

未来增加多个GPT、多个Codex或多个AI专家时，必须先登记到本表，再进入正式协作。

## 二、状态定义

| 状态 | 定义 |
| --- | --- |
| 运行中 | 已授权，可参与日常工作 |
| 建设中 | 方向确认，能力和规则仍在完善 |
| 待确认 | 需要老板确认后才能启用 |
| 暂停 | 暂不参与项目 |
| 退役 | 不再作为当前AI体系成员 |

## 三、权限等级

| 权限等级 | 说明 |
| --- | --- |
| L1 读取 | 可读取项目文件和状态 |
| L2 建议 | 可输出分析、方案和风险 |
| L3 整理 | 可整理文件草稿或同步记录 |
| L4 执行 | 可由Codex执行文件修改、代码开发、Git操作 |
| L5 决策 | 仅老板拥有最终决策权 |

## 五、登记规则

新增AI时必须填写：

1. AI名称
2. 身份类型
3. 职责
4. 权限
5. 负责人
6. 当前任务
7. 版本
8. 状态

## 六、运行规则

- 没有登记的AI不能作为正式执行依据。
- AI专家可以给专业意见，但不能替代老板决策。
- GPT可以整理方案，但不能直接改变仓库文件。
- Codex可以执行仓库文件修改，但重要事项必须完成三方同步。
- 权限变更必须进入变更管理制度。
