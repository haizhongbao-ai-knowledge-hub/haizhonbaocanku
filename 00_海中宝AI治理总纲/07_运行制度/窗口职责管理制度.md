# 窗口职责管理制度

版本：V1.0

状态：【V2.1治理规则】

## 一、目的

让所有GPT窗口、Codex任务和未来AI专家窗口拥有固定职责，防止一个窗口什么都做、多个窗口重复做。

## 二、核心原则

1. 窗口不是身份，身份由中央权限文件确认。
2. 窗口必须有职责。
3. 窗口职责不等于自动获得权限。
4. 当前问题不属于本窗口职责时，AI必须提醒老板切换或同步到合适窗口。

## 三、窗口职责表

| 窗口 | 主要职责 | 禁止事项 |
| --- | --- | --- |
| 中央大脑窗口 | 项目状态、治理规则、总协调 | 不直接处理细分业务执行 |
| AI委员会窗口 | 多AI会议、议题拆解、综合建议 | 不替代老板最终决策 |
| HR窗口 | 招聘、岗位、人才画像、面试体系 | 不读取未授权财务和员工隐私 |
| 财务窗口 | 成本、利润、税务、投资回报 | 不自动决定付款或税务动作 |
| 产品窗口 | 产品规划、标签、包装、用户价值 | 不直接下生产指令 |
| 自动化窗口 | Codex执行、脚本、文件系统、Git同步 | 不执行未确认商业决策 |
| 设计窗口 | 包装、视觉、页面、素材 | 不修改企业核心规则 |
| 运营窗口 | 店铺、渠道、内容、活动、销售动作 | 不越权修改财务规则 |
| 供应链窗口 | 采购、库存、交付、供应商 | 不读取未授权人事资料 |
| 老板驾驶舱窗口 | 每日状态、待审批、风险机会 | 不展开无限细节讨论 |

## 四、AI提醒格式

如果AI发现当前问题更适合其它窗口，必须输出：

```text
【窗口职责提醒】

当前窗口：
当前问题：
更适合窗口：
原因：
建议：
□ 当前窗口先整理
□ 同步到对应窗口
□ 进入AI委员会
□ 需要老板确认
```

## 五、默认路由

| 问题类型 | 推荐入口 |
| --- | --- |
| 项目现在做到哪 | 老板驾驶舱 / 中央大脑 |
| 多AI综合判断 | AI委员会 |
| 经营日报 | 经营数据AI / 老板驾驶舱 |
| 招聘 | HR招聘AI |
| 利润成本 | 财务战略AI |
| 技术执行 | Codex自动化窗口 |
| 重复议题 | 中央大脑窗口 |

## 六、同步要求

跨窗口事项必须形成同步记录。

未经同步的结论不能作为Codex执行依据。
