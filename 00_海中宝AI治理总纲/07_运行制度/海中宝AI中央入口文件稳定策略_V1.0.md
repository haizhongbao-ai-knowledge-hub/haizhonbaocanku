# 海中宝AI中央入口文件稳定策略 V1.0

状态：【启用】

更新日期：2026-07-29

## 一、目的

让老板手机、优盘、其他电脑中保存的中央大脑入口文件长期可用，避免每次中央大脑升级都要重新更换入口文件。

## 二、核心原则

入口文件是启动器，不是全部知识库。

入口文件负责：

- 识别海中宝AI中央大脑
- 指向中央导航地图
- 指向项目状态总览
- 指向身份权限验证
- 要求AI输出接入申请

入口文件不负责：

- 保存全部知识
- 保存全部权限
- 保存岗位知识库
- 保存真实业务数据
- 保存密码、口令、密钥

## 三、后续升级规则

以后中央大脑继续升级时，优先更新：

1. `接入包_给GPT和Codex/中央大脑导航地图.md`
2. `海中宝AI项目状态总览.md`
3. `00_海中宝AI治理总纲/07_运行制度/AI身份权限验证表.md`
4. `00_海中宝AI治理总纲/07_运行制度/AI接入状态中心_V1.0.md`
5. 具体岗位知识库和项目文件

除非入口流程发生重大变化，否则不频繁修改：

```text
接入包_给GPT和Codex/海中宝AI中央大脑智能体一键接入入口_V2.0.md
```

## 四、手机/优盘使用规则

老板手机或优盘中长期保存：

```text
海中宝AI中央大脑智能体一键接入入口_V2.0.md
```

未来新GPT、新Codex、新AI专家第一次接入时，仍然先上传这个文件。

AI读取后必须继续请求或读取最新中央文件，而不是只依赖入口文件本身。

## 五、AI读取后的要求

AI读取入口文件后，必须说明：

```text
我已读取入口文件。
入口文件只是启动器。
请提供或授权我读取最新中央导航地图、项目状态总览和身份权限验证表。
```

## 六、什么时候才需要更换手机入口文件

只有以下情况才需要更换：

- GitHub中央仓库地址变化
- 项目编号变化
- 入口文件命名规则变化
- 接入流程发生根本变化
- 老板明确要求升级入口文件主版本

普通制度升级、岗位增加、知识库增加、业务项目增加，不需要更换手机入口文件。
