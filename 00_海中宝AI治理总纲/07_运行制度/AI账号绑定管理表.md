# AI账号绑定管理表

状态：【启用】

更新日期：2026-07-29

## 一、用途

本表用于管理海中宝AI中央大脑中“人员身份、AI身份、GPT账号、Codex账号、GitHub权限”的对应关系。

目的：

- 新电脑可以恢复身份。
- 新GPT账号可以申请对应岗位权限。
- 新Codex账号可以判断执行范围。
- 不同人员和AI专家不会混用Owner权限。

## 二、重要安全原则

本表只记录账号绑定状态和权限等级。

禁止写入：

- GitHub密码
- ChatGPT密码
- Codex登录密码
- 邮箱验证码
- 手机验证码
- API Key
- 真实业务系统密码

真实认证信息只能通过老板指定的独立渠道确认。

## 五、权限说明

### HZB-OWNER-001 春晓V0

权限：

- 最终决策
- 项目优先级确认
- 权限授权
- GitHub Owner权限
- 宪法级文件最终确认

限制：

- 不建议在文件中保存个人账号密码
- 不建议把Owner权限授权给普通AI专家

### HZB-AI-CEO-001 伟强V1

权限：

- AI项目推进
- 任务协调
- 项目状态查看
- 提交GPT/Codex任务建议
- 读取授权范围内的治理、项目和状态资料

限制：

- 不能替代老板最终决策
- 不能自动修改AI宪法
- 不能自动开放Owner权限
- 不能读取未授权财务、人事隐私和老板敏感战略资料

### HZB-HR-AI-001 HR招聘AI

权限：

- 读取HR招聘AI知识库
- 生成JD、人才画像、简历评分、沟通话术、面试题库、候选人评价表

限制：

- 不读取财务核心数据
- 不读取员工隐私
- 不决定录用、淘汰和薪酬审批

## 六、新账号绑定流程

```text
上传入口文件
↓
读取中央导航地图
↓
读取项目状态总览
↓
提交身份申请
↓
匹配人员或AI身份编号
↓
老板确认
↓
Codex更新账号绑定管理表
↓
同步GitHub
↓
恢复对应权限
```

## 七、账号绑定状态

状态分为：

- 待登记
- 待认证
- 已认证
- 暂停
- 停用

## 八、永久原则

授权的是身份，不是单纯账号。

同一个GPT账号可以切换不同AI岗位，但每次都必须按当前身份和岗位重新判断权限。

Owner权限只属于老板身份，不随普通账号或AI专家自动继承。
