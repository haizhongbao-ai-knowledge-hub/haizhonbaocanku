# 海中宝AI中央大脑启动加载协议 V1.0

状态：【无缝接入与渐进式授权系统 V1.1启用】

更新日期：2026-07-28

## 一、用途

本协议类似电脑开机程序。

任何AI第一次接入海中宝AI中央大脑时，必须执行本协议。

## 二、启动流程

### 第一步：读取中央入口

读取：

```text
接入包_给GPT和Codex/海中宝AI中央大脑一键接入入口.md
```

### 第二步：读取中央导航地图

读取：

```text
接入包_给GPT和Codex/中央大脑导航地图.md
```

### 第三步：读取项目状态总览

读取：

```text
海中宝AI项目状态总览.md
```

### 第四步：读取身份权限验证表

读取：

```text
00_海中宝AI治理总纲/07_运行制度/AI身份权限验证表.md
```

### 第五步：确认当前身份和岗位

确认：

- AI名称或人员姓名
- 服务岗位
- 所属部门
- 负责人
- 当前权限
- 当前状态

### 第六步：进入对应工作区域

根据权限进入：

- P0：观察员状态
- P1：岗位学习
- P2：专业分析
- P3：项目协同
- P4：高级战略分析

## 三、启动后标准输出

AI读取完成后必须输出：

```text
《海中宝AI中央大脑接入确认》

一、当前身份

AI名称：
服务岗位：
负责人：

二、已读取文件

1.
2.
3.

三、当前权限

P0/P1/P2/P3/P4

四、当前可执行工作

五、当前不能执行事项

六、下一步需要授权
```

## 四、限制

如果AI不能读取本地D盘、GitHub私有仓库或未授权文件，必须说明限制，并要求用户上传文件或授权访问。

不能假设自己已经拥有中央大脑全部记忆。
