# AI中央同步规则 V1.0

状态：【V1.0初始化】

更新日期：2026-08-01

## 一、目的

保证所有AI、GPT、Codex、设备和账号都回到同一个中央大脑事实源。

## 二、唯一事实来源

海中宝AI中央大脑的正式事实来源是：

```text
GitHub中央仓库 + 本地中央仓库
```

聊天记录不是最终事实来源。

## 三、所有AI必须读取

新AI、新GPT、新Codex、新设备接入时，必须先读取：

```text
接入包_给GPT和Codex/海中宝AI中央大脑智能体一键接入入口_V2.0.md
```

然后读取：

- `接入包_给GPT和Codex/中央大脑导航地图.md`
- `海中宝AI项目状态总览.md`
- `00_海中宝AI治理总纲/07_运行制度/AI身份权限验证表.md`
- `00_海中宝AI治理总纲/07_运行制度/AI账号权限表.md`

## 四、重要输出归档规则

| 内容 | 归档位置 |
| --- | --- |
| 重要决策 | `DECISIONS.md` |
| 所有任务 | `TASKS.md` |
| 项目状态 | `海中宝AI项目状态总览.md` |
| 兼容状态入口 | `PROJECT_STATUS.md` |
| 三方同步 | `sync_records/三方同步确认记录/` |
| AI委员会会议 | `projects/AI委员会/meetings/` |
| 长期知识 | `knowledge-hub/` |

## 五、PROJECT_STATUS说明

`PROJECT_STATUS.md` 只作为兼容入口。

唯一状态正文仍然是：

```text
海中宝AI项目状态总览.md
```

禁止出现两个互相冲突的状态文件。

## 六、同步流程

```text
AI输出重要内容
↓
写入对应中央文件
↓
更新TASKS / DECISIONS / 状态总览
↓
建立同步记录
↓
Codex提交Git
↓
推送GitHub
↓
必要时18点后重试
```

## 七、禁止事项

- 禁止只保存在聊天里。
- 禁止只保存在个人电脑里。
- 禁止绕过GitHub中央仓库。
- 禁止未确认内容伪装成最终决策。
- 禁止保存真实密码、token和验证码。
