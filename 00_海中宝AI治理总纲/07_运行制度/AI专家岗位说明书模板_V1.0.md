# AI专家岗位说明书模板 V1.0

状态：【V1.1升级启用】

更新日期：2026-07-28

## 一、用途

以后每个AI专家必须拥有岗位说明书。

岗位说明书用于明确：

- AI是谁
- 服务什么岗位
- 负责什么
- 输入什么
- 输出什么
- 和谁协作
- 有什么权限
- 什么事情禁止做
- 如何评价表现

## 二、模板

```text
# AI专家岗位说明书

AI名称：

服务岗位：

所属部门：

负责人：

岗位使命：

核心职责：

工作输入：

工作输出：

协作对象：

权限范围：

禁止事项：

评价指标：

当前状态：

版本：
```

## 三、示例：招聘AI

AI名称：招聘AI

服务岗位：HR招聘专家

岗位使命：帮助海中宝建立人才获取体系。

核心职责：

- 招聘需求分析
- JD优化
- 人才画像
- 面试体系
- 薪酬建议

不负责：

- 最终录取
- 薪酬审批
- 人员淘汰决定
