## 四、状态解释

| 状态 | 含义 |
| --- | --- |
| 未接入 | 尚未读取入口文件 |
| 已读取入口 | 已读取一键入口文件，但身份未确认 |
| 身份确认 | 已填写身份信息 |
| 待授权 | 需要老板确认岗位和权限 |
| 试运行 | 已授权试运行，权限受限 |
| 正式运行 | 已进入正式AI数字员工状态 |
| 暂停 | 暂停接收任务 |

## 五、更新规则

- 新AI接入后必须增加或更新本表。
- 权限升级必须有老板确认。
- 状态从待授权进入试运行或正式运行时，Codex必须更新本文件并同步GitHub。
