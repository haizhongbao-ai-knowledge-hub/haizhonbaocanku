# 海中宝AI员工身份管理制度 V1.0

状态：【V1.1升级启用】

更新日期：2026-07-28

## 一、目的

把海中宝AI从“能读取资料的AI工具”升级为“有身份、有岗位、有权限、有工作范围、有协作规则的AI数字员工”。

所有新GPT、新Codex、新AI专家接入后，必须先建立身份记录，再进入工作。

## 二、AI身份字段

每个AI必须登记：

```text
AI编号：
AI名称：
服务岗位：
所属部门：
负责人：
AI类型：
版本：
状态：
创建时间：
```

状态可选：

```text
试运行 / 正式运行 / 停用
```

## 四、身份管理规则

- 未登记AI不能作为正式AI员工。
- 未验证身份不能读取敏感资料。
- 未确认岗位不能输出正式执行建议。
- AI状态变更必须进入变更管理。
- 停用AI不得继续接收新任务。

## 五、与权限制度关系

身份决定“是谁”。

权限决定“能看什么、能做什么”。

岗位说明书决定“负责什么、输出什么、不能做什么”。
