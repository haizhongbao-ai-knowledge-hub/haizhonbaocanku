## 三、每台电脑必须安装

| 软件 | 要求 |
| --- | --- |
| Chrome | 可登录GitHub和ChatGPT |
| ChatGPT | 浏览器版即可，桌面版可选 |
| Codex | 需要技术执行的电脑安装 |
| Git | 必须可执行clone、pull、push |

## 四、接入中央步骤

1. 登录GitHub。
2. clone中央仓库：

```text
https://github.com/haizhongbao-ai-knowledge-hub/haizhonbaocanku.git
```

3. 读取：

```text
00_老板驾驶舱/00_中央项目索引.md
00_老板驾驶舱/01_项目状态中心.md
接入包_给GPT和Codex/海中宝AI中央大脑智能体一键接入入口_V2.0.md
```

4. 填写或核对身份权限。
5. 运行Git状态检查。
6. 形成接入同步记录。

## 五、同步规则

1. 工作前先pull。
2. 修改后先本地提交。
3. 重要文件推送GitHub。
4. 推送失败进入18点后重试清单。
5. 不把真实密码和敏感凭据写入仓库。

## 六、验收标准

每台电脑验收必须回答：

1. 是否能打开GitHub仓库。
2. 是否能读取中央项目索引。
3. 是否能读取项目状态中心。
4. 是否能识别当前身份和权限。
5. 是否能完成Git pull。
6. 需要推送的电脑是否能完成Git push。
