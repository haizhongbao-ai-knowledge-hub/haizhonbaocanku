# V2启动操作说明

状态：【待V2设备上线执行】

## 一、老板需要准备

最少只需要准备：

1. V2电脑或V2运行环境。
2. 可访问GitHub中央仓库的账号。
3. Codex桌面版或可执行本地仓库任务的环境。
4. V2启动入口文件。

## 二、V2启动步骤

1. 在V2电脑安装Git。
2. 克隆GitHub中央仓库。
3. 打开Codex。
4. 上传或打开：

`接入包_给GPT和Codex/V2正式启动入口文件.md`

5. 要求V2读取启动文件中的全部核心文件。
6. V2输出《V2 AI研发协同中心启动确认》。
7. V2更新：

`00_老板驾驶舱/AI节点总览/V2_HEARTBEAT.md`

8. V0确认V2进入试运行。

## 三、第一项测试任务

建议任务：

```text
用统一任务入口提交一项低风险文件整理任务，由Dispatcher推荐V2执行，V0确认后执行。
```

验收：

1. V2能领取任务。
2. V2能更新Heartbeat。
3. V2能提交结果。
4. V0能看到回传。
5. GitHub中央仓库能收到正式结果。

## 四、上线状态升级

通过第一轮实测后：

```text
Pending Online -> 试运行
```

连续10个真实任务稳定后：

```text
试运行 -> 正式运行
```
