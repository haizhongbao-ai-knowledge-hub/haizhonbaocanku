# AI岗位授权加载流程 V1.0

状态：【中央大脑V2.0补充流程】

更新日期：2026-07-28

## 一、目标

完善中央大脑V2.0，使新GPT、新Codex、新电脑、新账号接入后，可以按以下流程进入岗位工作模式：

```text
身份识别
↓
岗位选择
↓
权限申请
↓
老板授权
↓
加载对应知识库
↓
进入岗位工作模式
```

## 二、一级接入

AI读取：

```text
接入包_给GPT和Codex/海中宝AI中央大脑智能体一键接入入口_V2.0.md
```

目标：

- 识别海中宝AI项目。
- 知道自己不能直接执行业务。
- 默认进入P0观察员状态。

## 三、二级身份确认

AI填写或输出：

```text
AI名称：
AI类型：
当前账号：
接入时间：
申请服务岗位：
负责人：
使用部门：
```

重要原则：

不是授权账号，而是授权智能体身份。

同一个GPT账号今天可以作为HR AI，明天可以作为产品AI。

真正决定工作模式的是：

- 入口文件
- 身份表
- 权限文件
- 岗位授权

## 四、三级权限授权

AI根据岗位申请权限。

权限必须经过老板确认。

权限等级：

```text
P0 观察员
P1 岗位学习
P2 专业分析
P3 项目协同
P4 高级战略分析
```

未授权前，不得读取敏感数据，不得输出执行方案。

## 五、四级知识加载

授权后，根据岗位加载对应知识库。

示例：

| 岗位AI | 加载知识库 |
| --- | --- |
| HR AI | 企业介绍、组织架构、岗位资料、薪酬制度、招聘流程、人才模型 |
| 财务AI | 财务制度、经营数据、成本、利润、税务资料 |
| 产品AI | 产品资料、用户反馈、竞品资料、供应链摘要 |
| 运营AI | 运营数据、渠道、店铺、广告、转化数据 |
| Codex | 技术文件、任务文件、同步记录、项目代码 |

## 六、五级岗位工作

AI进入岗位工作模式后，必须按岗位输出。

例如HR AI输出：

```text
问题分析
↓
资料依据
↓
方案
↓
风险
↓
给老板决策建议
↓
给Codex执行需求
```

## 七、禁止事项

- 不得把入口文件当作全部知识库。
- 不得把GPT账号当作企业员工账号授权。
- 不得未授权读取敏感资料。
- 不得自动执行重大事项。
- 不得绕过老板确认和三方同步。
