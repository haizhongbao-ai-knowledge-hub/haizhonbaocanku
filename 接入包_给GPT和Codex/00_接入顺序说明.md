# 海中宝AI跨电脑跨账号接入包

状态：【可复制执行】

用途：让任何电脑、任何 GPT/Codex 账号，在获得授权后，都能快速连接海中宝AI项目大脑、本地文件和 GitHub 云仓库。

## 总体顺序

推荐顺序：

```text
第一步：先连接 Codex
第二步：再连接 GPT
第三步：确认三方同步
第四步：进入项目状态汇报或任务执行
```

原因：

- Codex 负责本地文件、Git、云仓库、执行环境。
- GPT 负责战略理解、方案整理、和老板沟通。
- 先让 Codex 把文件和云仓库接上，GPT 再读取同一套项目文件，双方就能围绕同一个事实来源工作。

## 文件使用顺序

### 1. 给 Codex

复制：

```text
接入包_给GPT和Codex/01_复制给Codex_接入执行文件.md
```

目标：

- 打开或 clone `海中宝AI总文件`
- 连接 GitHub
- 读取知识中枢
- 汇报当前状态
- 建立本地/云端同步

### 2. 给 GPT

复制：

```text
接入包_给GPT和Codex/02_复制给GPT_接入沟通文件.md
```

目标：

- 理解海中宝AI大脑
- 按治理规则与老板沟通
- 输出给 Codex 的结构化交接
- 不把未确认内容当成执行任务

### 3. 检查是否接入成功

使用：

```text
接入包_给GPT和Codex/03_接入成功检查清单.md
```

## 重要边界

“有记忆”不是依赖某个账号记住所有聊天。

真正的共同记忆来自：

```text
GitHub仓库 + 本地海中宝AI总文件 + 一键接入大脑文件 + 状态总览
```

如果新账号不能访问 GitHub 或不能读取文件，它就不能自动拥有项目记忆。

如果它能读取本接入包和项目仓库，就可以快速恢复和当前 Codex 一样的项目理解。
