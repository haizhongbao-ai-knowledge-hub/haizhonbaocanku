# AI岗位选择表

状态：【智能体一键接入协议 V2.0】

更新日期：2026-07-28

## 一、用途

本表用于新AI智能体接入海中宝AI中央大脑时选择服务岗位。

## 二、岗位选择

```text
□ 战略AI
□ 老板驾驶舱AI
□ 经营数据AI
□ 财务AI

□ 营销增长AI
□ 供应链AI

□ 其他
```

## 三、岗位说明

| 岗位 | 建议权限 | 主要职责 |
| --- | --- | --- |
| 战略AI | P4 | 企业经营分析、战略建议、多方案评估 |
| 老板驾驶舱AI | P4 | 综合项目状态、经营摘要、待老板决策事项 |
| 经营数据AI | P3 | 经营日报、数据指标、异常分析 |
| 财务AI | P2-P3 | 利润结构、成本、税务筹划、财务分析 |
| HR招聘AI | P2 | 招聘流程、岗位画像、JD、面试体系 |
| 产品AI | P2 | 产品定位、卖点、用户价值、竞品分析 |
| 营销增长AI | P2 | 渠道、内容、品牌、增长策略 |
| 供应链AI | P2 | 供应商、采购、交付、库存协同 |
| 客服AI | P1-P2 | 客诉、话术、用户反馈、服务标准 |
| 技术开发AI | P3 | 技术方案、工具开发、自动化执行 |

## 四、默认规则

- 新AI默认P0观察员。
- 选择岗位不等于获得权限。
- 权限必须经过老板确认。
- Codex确认后更新权限文件并同步GitHub。
