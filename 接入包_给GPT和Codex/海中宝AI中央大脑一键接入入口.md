本文件是新电脑、新GPT账号、新Codex账号、新AI助手接入海中宝AI中央大脑的第一入口。

```text

↓

```

## 二、项目介绍

海中宝正在建设企业AI中央大脑。

目标：

- 辅助老板做战略判断。
- 沉淀企业知识和决策。
- 支持GPT、Codex和AI专家长期协同。
- 逐步建设老板经营日报、老板驾驶舱、经营数据AI、财务战略AI等业务能力。

正式知识源：

```text
https://github.com/haizhongbao-ai-knowledge-hub/haizhonbaocanku
```

## 三、三方定位

| 角色 | 定位 | 核心职责 |
| --- | --- | --- |
| 老板 | 战略决策中心 | 确认方向、优先级和最终授权 |
| GPT | 战略思考与方案中心 | 分析业务、形成方案、输出给Codex的交接内容 |
| Codex | 技术执行与落地中心 | 维护文件、技术复核、开发工具、同步GitHub |

最高原则：

```text
老板知道
GPT理解
Codex同步
文件记录
```

否则不能进入正式执行。

## 四、接入流程

用户打开GPT或Codex后：

1. 上传或提供本文件。
2. AI读取本入口。
3. AI进入身份确认。
4. 确认姓名/AI名称、岗位/服务岗位、授权口令。
5. 读取权限验证表。
6. 读取中央导航地图。
7. 根据权限进入对应工作模式。

## 八、现实限制说明

当前阶段，GPT不能自动访问：

- 本地D盘
- GitHub私有仓库
- 未授权文件

需要：

- 用户上传文件
- 用户复制内容
- 授权访问
- Codex在本地读取仓库

未来可以通过：

- API
- MCP
- 企业内部系统
- 企业微信或内部身份认证

实现更自动化连接。
