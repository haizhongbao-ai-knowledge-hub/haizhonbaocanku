# 海中宝AI中央大脑统一接入与权限管理制度 V1.0

状态：【初步设计版，待老板确认】

来源：GPT提交给Codex的中央大脑升级草案

归档日期：2026-07-28

## 一、建设目标

海中宝未来不是单独使用几个AI工具，而是建设“企业AI中央大脑系统”。

实现：

- 新电脑
- 新账号
- 新GPT
- 新Codex
- 新AI专家

只要经过授权，都可以接入同一个中央大脑。

所有AI必须：

- 遵守统一规则
- 读取统一知识
- 按岗位权限工作
- 留存工作记录

最终形成：

```text
中央大脑
+ AI专家团队
+ 执行系统
+ 企业知识库
```

## 二、中央大脑最高原则

所有AI必须遵守：

```text
老板知道
GPT理解
Codex同步
文件记录
```

否则不能进入正式执行。

## 三、中央大脑组成

GPT建议的中央大脑组成：

1. 00_AI宪法与规则中心
2. 01_公司战略知识库
3. 02_老板决策中心
4. 03_AI专家中心
5. 04_部门业务知识库
6. 05_项目管理中心
7. 06_任务执行中心
8. 07_AI权限管理中心
9. 08_同步记录中心
10. 09_历史复盘中心

## 四、AI统一接入机制

任何新AI加入必须执行：

1. 身份登记
2. 权限审核
3. 读取中央入口文件
4. 确认岗位职责
5. 确认可访问知识范围
6. 开始工作

## 五、AI身份档案

每个AI必须建立《AI身份权限档案》。

字段：

- AI名称
- AI岗位
- 所属部门
- 负责人
- 权限等级
- 可读取文件
- 可修改文件
- 可执行任务
- 是否可通知Codex
- 是否需要老板确认
- 输出标准

## 六、AI权限等级

### P0 观察型AI

权限：

- 读取公开资料
- 输出基础分析
- 禁止修改文件

### P1 辅助型AI

权限：

- 资料整理
- 数据汇总
- 报告生成
- 禁止直接执行

### P2 专业顾问AI

权限：

- 专业分析
- 方案设计
- 专业知识库维护
- 需要负责人确认

### P3 执行型AI

权限：

- 创建任务
- 提交Codex执行需求
- 推动项目执行
- 必须经过授权

### P4 核心管理AI

权限：

- 跨部门分析
- 战略辅助
- 经营判断
- 重大事项必须老板确认

## 七、不同AI数据隔离原则

岗位不同，权限不同。

例如：

招聘AI允许读取公司介绍、岗位资料、招聘标准、薪酬规则。

招聘AI禁止读取财务利润、老板战略文件、员工隐私。

财务AI允许读取财务数据、成本、利润、税务资料。

财务AI禁止读取招聘隐私、员工评价。

## 八、文件作为唯一事实来源

聊天记录只用于讨论。

正式文件作为企业事实。

所有AI必须优先读取：

- 中央入口文件
- 知识库
- 状态文件
- 规则文件

## 九、异常情况处理

如果GPT已经确认，但Codex未同步。

状态：【待同步】

禁止：

- 开发
- 执行
- 修改正式文件

必须生成同步记录。
