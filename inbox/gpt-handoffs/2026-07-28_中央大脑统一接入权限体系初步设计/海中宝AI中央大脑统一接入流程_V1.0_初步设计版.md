# 海中宝AI中央大脑统一接入流程 V1.0

状态：【初步设计版，待老板确认】

来源：GPT提交给Codex的中央大脑升级草案

归档日期：2026-07-28

## 一、新设备接入

适用：

- 新电脑
- 新GPT
- 新Codex
- 新AI账号

流程：

1. 获取中央入口文件
2. 读取AI宪法
3. 读取项目状态
4. 读取岗位权限
5. 确认身份
6. 开始工作

## 二、中央入口文件

统一入口：

```text
海中宝AI中央大脑入口.md
```

作用：

任何AI第一读取。

包含：

- 项目介绍
- 公司方向
- AI规则
- 文件位置
- 当前状态
- 权限说明

## 三、新AI启动指令

复制：

```text
你现在接入：

海中宝AI中央大脑。

请先读取：

1. 中央入口文件
2. AI宪法文件
3. 当前项目状态文件
4. 你的岗位权限文件

读取后输出：

1. 我的身份
2. 我的职责
3. 我的权限
4. 当前任务
5. 是否存在需要同步事项
```

## 四、离线恢复机制

如果电脑损坏，恢复流程：

1. 新电脑安装Git
2. 拉取中央仓库
3. 读取入口文件
4. 恢复权限
5. 恢复项目状态

目标：

任何设备都可以恢复企业AI大脑。
