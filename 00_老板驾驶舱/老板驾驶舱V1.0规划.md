# 老板驾驶舱 V1.0规划

版本：V1.0

状态：【目录与规则规划版】

负责人：春晓V0

执行负责人：Codex

## 一、定位

老板驾驶舱是春晓V0每天查看海中宝AI中央大脑和企业经营状态的统一入口。

第一阶段不开发页面。

先建立：

1. 目录。
2. 数据来源。
3. 更新规则。
4. 待审批事项。

## 二、目录结构

```text
00_老板驾驶舱/
├── 00_中央项目索引.md
├── 01_项目状态中心.md
├── 02_今日待办.md
├── 03_重大决策.md
├── 04_AI委员会状态.md
├── 05_经营日报状态.md
├── 06_版本更新记录.md
└── 老板驾驶舱V1.0规划.md
```

## 三、老板每天看到什么

| 模块 | 作用 | 数据来源 |
| --- | --- | --- |
| 项目状态 | 当前做到哪一步 | `01_项目状态中心.md` |
| AI委员会 | 有哪些会议、结果、待决策 | `04_AI委员会状态.md` |
| 今日经营 | 后续接入销售、成本、利润 | 老板经营日报MVP |
| 待审批 | 需要老板选择的事项 | `02_今日待办.md`、`TASKS.md` |
| 经营日报 | 每天经营摘要 | `projects/老板经营日报MVP/` |
| 项目进度 | 所有AI项目状态 | `TASKS.md`、`PROJECT_STATUS.md` |
| 重大风险 | 当前阻塞和风险 | `01_项目状态中心.md`、`reviews/` |
| 重大机会 | AI专家提出的机会 | AI委员会、经营数据AI |
| AI日报 | AI今天做了什么 | `sync_records/`、Git提交 |

## 四、更新规则

| 场景 | 必须更新 |
| --- | --- |
| 完成重要任务 | 项目状态中心、TASKS、同步记录 |
| 形成重大决策 | 重大决策、DECISIONS |
| 开AI委员会 | AI委员会状态、会议目录 |
| 经营日报输出 | 经营日报状态 |
| 新电脑接入 | AI资产管理系统、6台电脑部署规范 |
| 新AI接入 | AI状态中心、身份权限表 |

## 五、第一阶段不做

1. 不做网页。
2. 不做APP。
3. 不做复杂权限后台。
4. 不直接接入敏感经营数据。

## 六、验收标准

老板打开 `00_中央项目索引.md` 和 `01_项目状态中心.md` 后，5分钟内能知道：

1. 现在完成多少。
2. 有哪些项目。
3. 有哪些AI。
4. 有哪些电脑。
5. 今天应该做什么。
6. 下一步是谁负责。
