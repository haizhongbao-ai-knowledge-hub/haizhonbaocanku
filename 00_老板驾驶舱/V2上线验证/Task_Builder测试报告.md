# Task Builder测试报告

状态：【测试框架已建立，真实任务卡生成待验证】

版本：V1.0

## 一、测试目标

验证正式任务能否从老板或GPT的自然语言要求，整理为可执行任务卡，并进入中央任务中心。

## 二、标准任务卡字段

| 字段 | 说明 |
| --- | --- |
| 任务编号 | 唯一编号 |
| 任务标题 | 一句话说明 |
| 来源 | 春晓V0、伟强V1、GPT、AI委员会等 |
| 优先级 | P0/P1/P2/P3 |
| 执行节点 | V0 Codex、V2 Codex、伟强V1、AI委员会 |
| 输入文件 | 任务依据文件 |
| 输出文件 | 需要生成或修改的文件 |
| 权限要求 | 是否需要老板确认 |
| 风险等级 | 低/中/高 |
| 验收标准 | 完成后怎么判断 |
| 当前状态 | 待澄清/待执行/执行中/待审查/已完成 |
