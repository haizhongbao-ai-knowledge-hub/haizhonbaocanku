# 海中宝GPT-Codex协同规则总结 V1.0

状态：【初步确认】

版本：V1.0

## 一、核心原则

GPT 负责：想清楚。

Codex 负责：做出来。

老板负责：决定方向。

## 二、项目流程

重要项目必须遵循：

```text
老板 → GPT → Codex → GPT → 老板 → 执行
```

## 三、文档管理原则

所有内容分三级：

### 一级：正式知识

进入长期系统。

例如：最终方案、老板确认的原则、正式决策。

### 二级：讨论方向

保存，但不能执行。

需要再次确认。

### 三级：聊天交流

只用于沟通。

不进入长期知识。

## 四、版本管理

所有文件必须注明状态：

- 初步方案
- 待优化方案
- 最终确认版
- Codex执行版

## 五、Codex执行规则

收到 GPT 方案：

1. 确认理解。
2. 输出技术方案。
3. 提出风险。
4. 等待确认。
5. 执行。

## 六、GPT输出规则

以后重要输出必须包含：

- 文件名称
- 状态
- 老板阅读提示
- 正文
- 下一步建议

## 七、老板日常管理方式

老板可以问：

```text
GPT，AI项目进展如何？
```

GPT 只提供分类总结，例如：

- 战略建设
- 技术建设
- 项目推进
- 待决策事项

老板需要深入时，再追问具体项目。
