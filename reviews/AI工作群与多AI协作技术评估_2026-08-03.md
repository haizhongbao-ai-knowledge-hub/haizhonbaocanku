# AI工作群与多AI协作技术评估

状态：【Codex技术评估完成，待老板确认】

评估日期：2026-08-03

## 一、结论

建议第一阶段采用：

```text
GitHub / 本地中央仓库 = 唯一事实来源
企业微信群机器人 = 通知通道
个人微信 / QQ群 = 人工沟通备用
```

不建议现在把微信群、QQ群或任何聊天群作为中央大脑事实源。

群聊只能提醒：

- 有新决策。
- 有新任务。
- 有异常。
- 有文件需要老板确认。
- 有GitHub推送失败需要处理。

正式事实必须回到：

```text
海中宝AI总文件
GitHub中央仓库
sync_records
TASKS.md
DECISIONS.md
海中宝AI项目状态总览.md
```

## 二、评估对象

| 方案 | 适合程度 | 建议 |
| --- | --- | --- |
| GitHub + 本地仓库 | 最高 | 继续作为唯一事实来源 |
| 企业微信群机器人 | 高 | 适合作为通知层 |
| 个人微信工作群 | 中 | 只做人和人沟通，不做自动化事实源 |
| QQ群机器人 | 中 | 可作为后续备选，不作为第一阶段主通道 |
| 自建网页工作台 | 后期适合 | 等业务MVP跑通后再开发 |

## 三、为什么企业微信优先

企业微信群机器人适合第一阶段原因：

- 支持Webhook推送，适合自动发送通知。
- 更接近企业管理场景。
- 比个人微信更适合权限、组织和后续自动化。
- 可以接收来自脚本、自动化任务、监控任务的提醒。

重要限制：

- 企业微信群机器人主要适合“主动推送消息”。
- Webhook地址相当于敏感凭据，不能提交到GitHub。
- 群消息不是正式事实来源。
- 群机器人不代表AI自动拥有执行权限。

## 四、个人微信评估

个人微信适合：

- 老板、伟强V1、员工日常沟通。
- 人工转发文件。
- 临时确认事项。

不适合：

- 作为AI中央大脑事实源。
- 存放长期决策。
- 自动抓取和归档全部消息。
- 保存权限记录。

原因：

- 自动化接入稳定性和合规边界不如企业微信。
- 聊天记录容易分散。
- 多设备、多账号、多AI接入时难以保持统一事实。

## 五、QQ群评估

QQ群或频道机器人可以作为后续备选。

适合：

- 技术测试。
- 机器人互动实验。
- 非核心通知通道。

第一阶段不建议作为主方案：

- 海中宝内部管理场景更适合企业微信。
- 当前目标不是聊天机器人，而是企业AI中央大脑。
- 过早接入多个消息平台会增加维护成本。

## 六、推荐架构

```text
GPT / Codex / AI专家
↓
正式文件更新
↓
Git本地提交
↓
GitHub中央仓库
↓
生成AI同步通知
↓
企业微信群机器人推送提醒
↓
老板 / 伟强V1 / 相关负责人查看
```

核心原则：

```text
群聊只通知
仓库才记录
老板最终确认
Codex按文件执行
```

## 七、第一阶段MVP

### 建议建立一个企业微信群

群名称：

```text
海中宝AI中央大脑工作群
```

成员：

- Codex负责人
- GPT负责人

### 通知类型

第一版只推送5类消息：

| 类型 | 示例 |
| --- | --- |
| 决策待确认 | 老板经营日报MVP等待老板确认 |
| 文件已更新 | 老板驾驶舱V2.0执行评估已归档 |
| GitHub同步异常 | Git凭据不可用，当前本地ahead 5 |
| AI专家状态 | 第一批AI专家岗位说明书已建立 |
| 每日18点后重试结果 | 未完成上传同步重试结果 |

## 八、暂不开发内容

第一阶段不做：

- 自动读取老板微信聊天记录。
- 自动把群聊内容写入中央仓库。
- 自动授权AI权限。
- 自动执行商业决策。
- 自动读取敏感经营数据。
- 多平台同时接入。

## 九、安全规则

禁止保存到GitHub：

- 企业微信群机器人Webhook完整地址。
- 微信、QQ、GitHub、ChatGPT、Codex密码。
- API Key。
- 验证码。
- 员工个人隐私。
- 客户个人隐私。
- 未脱敏财务流水。

建议做法：

- Webhook只保存在本地环境变量或本机安全配置。
- GitHub只保存配置模板。
- 推送内容只包含摘要和文件路径，不包含敏感明细。
- 重大事项仍需老板确认。

原因：

- GitHub凭据当前仍不可用，先不扩大自动化范围。
- Webhook需要老板或管理员在企业微信中创建，并通过安全方式提供。
- 不能把真实Webhook写进仓库。

## 十二、评估结论

当前最稳路线：

```text
先保住中央仓库事实源
再加企业微信通知
不让群聊替代仓库
不让机器人绕过权限
```

这条路线符合：

```text
老板知道
GPT理解
Codex同步
文件记录
否则不能执行
```
