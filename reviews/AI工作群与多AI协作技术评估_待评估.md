# AI工作群与多AI协作技术评估

状态：【待Codex技术评估】

## 背景

老板提出建立微信工作群 / QQ群 / 企业微信等“AI项目工作群”的方向。

目标：

- 同步决策
- 同步任务
- 同步异常
- 同步进度

成员可能包括：

- 老板
- GPT负责人
- Codex负责人
- 各专业AI负责人

## 待评估问题

1. 微信是否支持稳定自动化接入？
2. QQ是否更适合机器人？
3. 企业微信是否更适合企业级权限和自动化？
4. 是否应该先使用 GitHub 项目仓库作为唯一同步中心？
5. 是否需要消息群和项目仓库并行？

## 初步判断

在没有完成技术评估前，不建议把微信群/QQ群作为唯一事实来源。

建议仍以 GitHub 项目仓库为唯一事实来源，群聊只作为通知和沟通通道。
