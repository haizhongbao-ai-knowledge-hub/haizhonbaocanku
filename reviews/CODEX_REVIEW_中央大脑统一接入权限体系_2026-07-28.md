# Codex复核：中央大脑统一接入与权限体系

状态：【Codex复核完成，待老板确认是否升级正式制度】

日期：2026-07-28

## 一、我理解GPT要的目标

GPT这次要解决的不是单个文件问题，而是让海中宝AI中央大脑具备长期扩展能力。

目标是：

- 新电脑可以恢复同一个中央大脑。
- 新GPT、新Codex、新AI专家可以统一接入。
- 每个AI都有身份、岗位、权限和边界。
- 不同AI只能读取授权范围内的资料。
- 所有重要事项仍遵守“老板知道、GPT理解、Codex同步、文件记录”。

## 二、Codex判断

可以完成。

但不建议马上按GPT草案创建一套新的根目录：

```text
00_AI宪法与规则
01_中央入口
02_AI身份权限
...
```

原因：

当前仓库已经建立了正式结构：

```text
00_海中宝AI治理总纲
architecture
knowledge-hub
projects
tasks
sync_records
reviews
接入包_给GPT和Codex
```

如果现在再新建一套平行根目录，会造成两个问题：

1. 新AI不知道以哪一套目录为准。
2. 后续文件会分散，削弱“唯一事实来源”。

## 五、风险

1. 目录重复风险：如果直接新建GPT建议的整套根目录，会和现有目录冲突。
2. 权限过度开放风险：P3/P4不能直接等于自动执行，仍要老板授权。
3. 数据隔离风险：招聘、财务、人事等敏感资料必须分层授权，不能默认所有AI可读。
4. 文件格式风险：`xlsx`不利于Git版本对比，第一阶段建议继续用Markdown表格；后续真实数据表再用Excel。
5. 执行顺序风险：当前已确认下一阶段重点是老板经营日报MVP和老板驾驶舱V2，权限体系升级应作为支撑工作，不应抢走业务MVP优先级。
