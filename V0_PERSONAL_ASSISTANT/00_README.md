# V0 全能 AI 助理中心

这是春晓 V0 的长期个人 AI 中心，用于承接手机端、电脑端和云端长期对话，并按权限读取和沉淀海中宝中央仓库与个人上下文。

## 模块定位

- 统一个人问题入口。
- 统一企业、工作、家庭、学习、生活问题分析。
- 统一候选沉淀与确认写入流程。
- 统一权限分层与最小读取原则。

## 数据范围

- 企业上下文
- 个人上下文
- 家庭上下文
- 当前事项
- 长期偏好
- 决策记录
- 待确认候选

## 读取规则

1. 默认只读。
2. 先读当前上下文，再读长期偏好，再读相关决策。
3. 只按任务需要读取最小范围。
4. 涉及家庭或隐私时，默认禁止跨层读取。

## 写入规则

1. 普通聊天不直接写入正式区。
2. 先进入 `INBOX/PENDING` 候选区。
3. 必须经 V0 明确确认后，才能写入正式区。
4. 正式写入要保留来源、时间和原因。

## 与其他 AI 的关系

- 战略 AI：读取企业共享上下文。
- 财务 AI：读取财务相关授权内容。
- HR AI：读取人员与薪酬相关授权内容。
- 数据分析 AI：只读授权数据集与决策背景。
- 执行型 AI：只读当前任务最小范围。

## 禁止事项

- 不得把家庭隐私默认开放给其他 AI。
- 不得把未确认内容写成事实。
- 不得因能访问仓库就遍历全部内容。
- 不得破坏原有中央结构。
