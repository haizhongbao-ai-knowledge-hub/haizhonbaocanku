| 目录 | 用途 |
|---|---|
| `ENTERPRISE_CONTEXT/` | 海中宝企业事实、管理偏好、战略输入 |
| `PERSONAL_CONTEXT/` | 工作偏好、个人目标、成长记录 |
| `FAMILY_CONTEXT/` | 家庭偏好、家庭计划、私密备注 |
| `DECISION_LOG/` | 已确认决策的历史留痕 |
| `INBOX/PENDING/` | 待确认候选 |
| `INBOX/APPROVED/` | 已确认待归档内容 |
| `INBOX/REJECTED/` | 被拒绝或撤回的候选 |
| `TEMPLATES/` | 标准写入模板 |
