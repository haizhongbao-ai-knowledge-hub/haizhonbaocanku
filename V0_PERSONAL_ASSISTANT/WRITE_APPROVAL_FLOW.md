# Write Approval Flow

## 总流程

普通聊天 -> 候选生成 -> V0 确认 -> 分类 -> 写入 -> 留痕

## 普通聊天

不保存。

## 建议沉淀

写入：

`INBOX/PENDING/`

## V0 明确确认

以下指令视为确认：

- 确定，进入中央
- 保存到中央
- 这条定下来
- 以后按这个执行
- 记录为长期规则

## 正式写入位置

| 类型 | 位置 |
|---|---|
| 当前事项 | `CURRENT_CONTEXT.md` |
| 长期偏好 | `LONG_TERM_PROFILE.md` |
| 企业信息 | `ENTERPRISE_CONTEXT/` |
| 个人信息 | `PERSONAL_CONTEXT/` |
| 家庭信息 | `FAMILY_CONTEXT/` |
| 重要决策 | `DECISION_LOG/` |
